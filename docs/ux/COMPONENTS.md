# Definição de Componentes UI - ERP
Data: 2026-08-06

## Padrões de Layout
- **PageContainer**: Margens e padding padrão para telas cheias.
- **PageHeader**: Título, descrição e área de ações globais.
- **KPICard**: Cards informativos com ícones e variações de cor (accentColor).

## Componentes de Dados
- **DataTable**: Tabelas com suporte a sorting, filtros e paginação (TanStack Table).
- **EmptyState**: Feedback visual quando não há registros.
- **LoadingState**: Skeletons ou spinners padronizados.

## Interações
- **Dialogs**: Modais para formulários rápidos (Check-in, Cadastro).
- **Toasts**: Notificações de sucesso/erro via Sonner.
