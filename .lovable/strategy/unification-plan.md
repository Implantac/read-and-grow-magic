# Plano de Integração e Unificação do Ecossistema Read & Grow

## Objetivo
Transformar o sistema de um conjunto de ferramentas isoladas em um ecossistema ERP coeso, onde cada módulo atua como parte de um organismo vivo, eliminando a sensação de "sistemas individuais".

## Diagnóstico da "Sensação de Isolamento"
- Navegação segmentada por silos.
- Falta de dashboards transversais que conectam fluxos (ex: Venda -> Estoque -> Financeiro -> Fiscal).
- Terminologias inconsistentes entre módulos.
- Ausência de indicadores de impacto entre departamentos.

## Ações Propostas

### 1. Unified Navigation & Global Workspace
- Implementar o "Global Breadcrumb" que mostra o contexto do fluxo, não apenas o caminho da pasta.
- Criar o "Workflow Switcher": um atalho (Cmd/Ctrl + K) para pular entre etapas de um mesmo processo (ex: da NF-e para a Baixa Financeira).

### 2. Painel de Controle de Fluxos (Flow Control)
- Substituir menus estáticos por uma visão de pipeline ponta a ponta (O2C/P2P).
- Cada módulo deve exibir "Dependencies": o que ele precisa do módulo anterior e o que ele entrega para o próximo.

### 3. Cérebro Compartilhado (AI Context)
- A IA Executiva deve ter memória trans-departamental. Se o WMS está lento, o Comercial deve ser alertado sobre prazos de entrega.

### 4. Padronização Visual e de Linguagem
- Revisão de labels para usar o dicionário padrão Read & Grow em todos os módulos.
- Unificação de componentes de feedback (Skeletons, Empty States, Toasts) seguindo o UEEF Design System.
